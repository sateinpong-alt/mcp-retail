## PU-02 การคัดเลือกและอนุมัติผู้ขาย

**ขั้นตอน**
1. ผู้ขายรายใหม่ต้องส่งเอกสารครบก่อนเปิดบัญชี:
   - หนังสือรับรองบริษัท / ทะเบียนพาณิชย์
   - ภ.พ.20 (กรณีจดทะเบียน VAT)
   - หน้าสมุดบัญชีธนาคารในนามนิติบุคคล/เจ้าของกิจการ
   - ใบเสนอราคา และเงื่อนไขการชำระเงิน
   - เอกสาร อย. / มอก. (กรณีสินค้าที่กฎหมายกำหนด)
2. เปรียบเทียบใบเสนอราคาอย่างน้อย **[2–3] ราย** สำหรับสินค้าที่มูลค่าสั่งซื้อต่อครั้งเกิน [10,000] บาท
3. เกณฑ์การให้คะแนน: ราคา / คุณภาพ / Lead time / เงื่อนไขเครดิต / นโยบายคืนสินค้าและสินค้าใกล้หมดอายุ
4. ผู้จัดการร้านลงนามอนุมัติในทะเบียนผู้ขาย จึงเริ่มสั่งซื้อได้
5. ทบทวนผู้ขายหลักทุก [6] เดือน โดยดูอัตราส่งของครบ ตรงเวลา และจำนวนครั้งที่มีปัญหาคุณภาพ

**ข้อห้าม:** ห้ามรับของขวัญ เงิน หรือผลประโยชน์ส่วนตัวจากผู้ขาย ต้องแจ้งผู้จัดการร้านทุกกรณี
