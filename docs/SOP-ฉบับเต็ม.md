# ส่วนที่ 1 — โครงสร้างและความรับผิดชอบ

| ตำแหน่ง | ความรับผิดชอบหลัก |
|---|---|
| เจ้าของร้าน / ผู้จัดการร้าน | อนุมัติผู้ขายรายใหม่ อนุมัติ PO เกินวงเงิน อนุมัติราคาขายและส่วนลด ตรวจสอบผลนับสต็อก |
| ผู้รับผิดชอบจัดซื้อ | วางแผนสั่งซื้อ ออก PO ต่อรองราคา ติดตามของ ตรวจสอบใบวางบิล |
| หัวหน้ากะ / หัวหน้าหน้าร้าน | เปิด–ปิดร้าน ควบคุมเงินสด ดูแลการเติมสินค้า แก้ปัญหาลูกค้าเบื้องต้น |
| พนักงานขาย / แคชเชียร์ | ขาย รับชำระเงิน จัดเรียงสินค้า ตรวจวันหมดอายุ ดูแลความสะอาด |
| ผู้ตรวจรับสินค้า | ตรวจนับ ตรวจคุณภาพ ตรวจวันหมดอายุ ออก GRN |

**หลักการแบ่งแยกหน้าที่ (ห้ามละเมิด):**
1. ผู้สั่งซื้อ ต้องไม่ใช่คนเดียวกับผู้ตรวจรับสินค้า
2. ผู้ตรวจรับ ต้องไม่ใช่คนเดียวกับผู้อนุมัติจ่ายเงิน
3. ผู้นับสต็อก ต้องไม่ใช่ผู้รับผิดชอบสินค้ากลุ่มนั้นเพียงคนเดียว ต้องมีคนที่สองร่วมนับ

# ส่วนที่ 2 — SOP ฝ่ายจัดซื้อ

## PU-01 การวางแผนและกำหนดจุดสั่งซื้อ

**วัตถุประสงค์:** ให้มีสินค้าขายต่อเนื่องโดยไม่จมสต็อก

**ขั้นตอน**
1. กำหนดข้อมูลพื้นฐานของทุก SKU ในระบบ:
   - ยอดขายเฉลี่ยต่อวัน (คำนวณจากยอดขาย 30 วันย้อนหลัง)
   - Lead time ของผู้ขาย (วันที่สั่งถึงวันที่ของถึงร้าน)
   - Safety stock = ยอดขายเฉลี่ยต่อวัน × [3–7] วัน
2. คำนวณจุดสั่งซื้อ (Reorder Point):
   `ROP = (ยอดขายเฉลี่ยต่อวัน × Lead time) + Safety stock`
3. ทุกวัน[จันทร์/พฤหัสบดี] ผู้รับผิดชอบจัดซื้อดึงรายงานสินค้าต่ำกว่า ROP จากระบบ POS
4. ตรวจสอบก่อนสั่งทุกครั้ง:
   - มีของค้างในสต็อกหลังร้านหรือไม่
   - มีโปรโมชั่น เทศกาล หรือ High season ที่ต้องเพิ่มยอดหรือไม่
   - สินค้าตัวนี้เป็นสินค้าที่ขายช้า (ไม่มีการขายเกิน [60] วัน) หรือไม่ — ถ้าใช่ **ห้ามสั่งซ้ำ** ให้เสนอระบายสต็อกแทน
5. สรุปเป็นใบขอสั่งซื้อ (PR) แยกตามผู้ขาย

**ความถี่:** สัปดาห์ละ [2] ครั้ง / สินค้าสดรายวัน

## PU-02 การคัดเลือกและอนุมัติผู้ขาย

**ขั้นตอน**
1. ผู้ขายรายใหม่ต้องส่งเอกสารครบก่อนเปิดบัญชี:
   - หนังสือรับรองบริษัท / ทะเบียนพาณิชย์
   - ภ.พ.20 (กรณีจดทะเบียน VAT)
   - หน้าสมุดบัญชีธนาคารในนามนิติบุคคล/เจ้าของกิจการ
   - ใบเสนอราคา และเงื่อนไขการชำระเงิน
   - เอกสาร อย. / มอก. (กรณีสินค้าที่กฎหมายกำหนด)
2. เปรียบเทียบใบเสนอราคาอย่างน้อย **[2–3] ราย** สำหรับสินค้าที่มูลค่าสั่งซื้อต่อครั้งเกิน [10,000] บาท
3. เกณฑ์การให้คะแนน: ราคา / คุณภาพ / Lead time / เงื่อนไขเครดิต / นโยบายคืนสินค้าและสินค้าใกล้หมดอายุ
4. ผู้จัดการร้านลงนามอนุมัติในทะเบียนผู้ขาย จึงเริ่มสั่งซื้อได้
5. ทบทวนผู้ขายหลักทุก [6] เดือน โดยดูอัตราส่งของครบ ตรงเวลา และจำนวนครั้งที่มีปัญหาคุณภาพ

**ข้อห้าม:** ห้ามรับของขวัญ เงิน หรือผลประโยชน์ส่วนตัวจากผู้ขาย ต้องแจ้งผู้จัดการร้านทุกกรณี

---

## PU-03 การออกใบสั่งซื้อ (PO) และอำนาจอนุมัติ

**ขั้นตอน**
1. ออก PO จากระบบทุกครั้ง **ห้ามสั่งด้วยวาจาหรือแชทอย่างเดียว** (กรณีเร่งด่วนสั่งทางโทรศัพท์ได้ แต่ต้องออก PO ย้อนหลังภายในวันเดียวกัน)
2. PO ต้องระบุครบ: ชื่อผู้ขาย / รหัสสินค้า / จำนวน / ราคาต่อหน่วย / ส่วนลด / VAT / วันที่ต้องการรับของ / สถานที่ส่ง
3. อำนาจอนุมัติ (ปรับตามร้าน):

| มูลค่า PO (รวม VAT) | ผู้อนุมัติ |
|---|---|
| ไม่เกิน [5,000] บาท | หัวหน้ากะ / ผู้รับผิดชอบจัดซื้อ |
| [5,001–50,000] บาท | ผู้จัดการร้าน |
| เกิน [50,000] บาท | เจ้าของร้าน / กรรมการ |

4. ส่ง PO ให้ผู้ขายทางอีเมลหรือช่องทางที่บันทึกได้ และเก็บหลักฐานการส่ง
5. ติดตามสถานะ PO ที่ยังไม่ได้รับของทุกสัปดาห์ PO ที่เกินกำหนดรับเกิน [7] วัน ให้ยกเลิกหรือยืนยันใหม่

---

## PU-04 การรับและตรวจรับสินค้า (GRN)

**ผู้รับผิดชอบ:** ผู้ตรวจรับสินค้า (ไม่ใช่คนสั่งซื้อ)

**ขั้นตอน**
1. รับของเฉพาะช่วงเวลาที่กำหนด: [เวลา __:__ – __:__] เพื่อไม่ให้กระทบเวลาขายหน้าร้าน
2. ตรวจเอกสารก่อนขนของลง: ใบส่งของต้องตรงกับ PO ทั้งเลขที่ ชื่อสินค้า และจำนวน
3. ตรวจสินค้า:
   - นับจำนวนจริงทีละรายการ **ห้ามเซ็นรับโดยไม่นับ**
   - ตรวจสภาพบรรจุภัณฑ์ รอยบุบ ฉีก เปียก
   - ตรวจวันหมดอายุ — ต้องเหลืออายุไม่น้อยกว่า [70%] ของอายุสินค้า หรืออย่างน้อย [__] วัน
   - ตรวจอุณหภูมิสำหรับสินค้าแช่เย็น/แช่แข็ง และบันทึกลงแบบฟอร์ม
4. กรณีพบปัญหา:
   - ของขาด → รับเท่าที่ได้จริง แก้ไขจำนวนในใบส่งของ ให้คนส่งเซ็นกำกับ
   - ของเสียหาย/ใกล้หมดอายุ → ปฏิเสธการรับ และบันทึกในใบตรวจรับ
   - ของเกิน / ไม่ได้สั่ง → ไม่รับ
5. บันทึกรับเข้าระบบ (GRN) **ภายในวันเดียวกัน** ห้ามค้างข้ามวัน
6. นำของเข้าสต็อกตามหลัก FEFO (หมดอายุก่อน–ออกก่อน) โดยวางของใหม่ไว้ด้านหลัง
7. รวบรวมชุดเอกสาร: PO + ใบส่งของ + GRN + ใบกำกับภาษี ส่งบัญชีทุกวัน[ศุกร์]

## PU-05 การคืนสินค้าและเคลม

**ขั้นตอน**
1. แยกสินค้าที่มีปัญหาไว้ในพื้นที่ "รอคืน" ติดป้ายชัดเจน **ห้ามวางปนกับสินค้าขาย**
2. ออกใบคืนสินค้าระบุ: เหตุผล (ชำรุด / ใกล้หมดอายุ / ส่งผิด / ขายไม่ออกตามเงื่อนไข) จำนวน และมูลค่า
3. แจ้งผู้ขายภายใน [3] วันทำการ นับจากวันที่พบปัญหา
4. ติดตามใบลดหนี้ (Credit Note) และตรวจว่าถูกนำไปหักในรอบวางบิลถัดไป
5. ปิดรายการในระบบเมื่อได้รับใบลดหนี้แล้วเท่านั้น

---

## PU-06 การตั้งราคาขาย

1. ตั้งราคาจากต้นทุนสุทธิ (หลังหักส่วนลด) ตามอัตรากำไรขั้นต้นเป้าหมายของแต่ละกลุ่มสินค้า:

| กลุ่มสินค้า | GP% เป้าหมาย |
|---|---|
| [กลุ่ม A] | [__]% |
| [กลุ่ม B] | [__]% |
| [กลุ่ม C] | [__]% |

2. ตรวจสอบราคาคู่แข่งในพื้นที่อย่างน้อยไตรมาสละครั้งสำหรับสินค้าขายดี [20] อันดับแรก
3. เมื่อต้นทุนเปลี่ยน ให้เสนอปรับราคาต่อผู้จัดการร้านก่อน **ห้ามพนักงานแก้ราคาในระบบเอง**
4. เปลี่ยนป้ายราคาหน้าชั้นให้ตรงกับระบบ **ในวันเดียวกับที่ปรับราคา** และตรวจซ้ำก่อนเปิดร้านวันถัดไป

---

## PU-07 การวางบิลและชำระเงิน

1. รับวางบิลเฉพาะวัน[อังคาร] เวลา [__:__ – __:__]
2. ตรวจสอบ 3 ทาง (3-way match): PO ↔ GRN ↔ ใบแจ้งหนี้/ใบกำกับภาษี ต้องตรงกันทั้งจำนวนและราคา
3. หากไม่ตรง ให้พักการจ่ายและแจ้งผู้ขายแก้ไขก่อน ห้ามจ่ายไปก่อนแล้วตามแก้ทีหลัง
4. จ่ายเงินตามเครดิตเทอมที่ตกลง (ปกติ [30] วัน) โดยโอนเข้าบัญชีในนามผู้ขายเท่านั้น
5. ผู้อนุมัติจ่ายเงินต้องเป็นคนละคนกับผู้ตรวจรับสินค้า

# ส่วนที่ 3 — SOP หน้าร้าน

## FS-01 การเปิดร้าน

**เวลา:** ก่อนเปิด [45–60] นาที

**เช็กลิสต์**
1. ตรวจสภาพร้านรอบนอก ประตู กระจก กล้องวงจรปิด ระบบสัญญาณกันขโมย
2. เปิดไฟ แอร์ ระบบเสียง และตรวจอุณหภูมิตู้แช่ทุกตู้ พร้อมบันทึกค่า
3. เปิดระบบ POS ตรวจว่าเชื่อมต่อเครื่องรูดบัตร/QR ได้ ตรวจกระดาษใบเสร็จ
4. นับเงินทอนตั้งต้นในลิ้นชักให้ครบ [__] บาท ต่อหน้าพยาน 1 คน แล้วเซ็นในใบส่งกะ
5. เดินตรวจชั้นวาง: สินค้าเต็ม หน้าตรง ป้ายราคาตรงกับระบบ ไม่มีสินค้าหมดอายุ
6. ตรวจความสะอาดพื้น ห้องน้ำ และจุดชำระเงิน
7. หัวหน้ากะเซ็นรับรองเช็กลิสต์เปิดร้าน

---

## FS-02 การบริการลูกค้าและการขาย

**มาตรฐานการบริการ**
1. ทักทายลูกค้าทุกคนภายใน [10] วินาทีที่เข้าร้าน
2. เข้าเสนอความช่วยเหลือเมื่อลูกค้าหยุดดูสินค้าเกิน [30] วินาที ด้วยคำถามปลายเปิด ไม่ใช่ "หาอะไรอยู่คะ"
3. รู้ข้อมูลสินค้าโปรโมชั่นประจำสัปดาห์ทุกคน — หัวหน้ากะบรีฟก่อนเริ่มกะทุกวัน [5] นาที
4. เสนอสินค้าต่อเนื่อง (add-on) อย่างน้อย 1 รายการต่อการขาย โดยไม่กดดันลูกค้า
5. ไม่ยืนคุยกันเป็นกลุ่ม ไม่ใช้โทรศัพท์ส่วนตัวในพื้นที่ขาย

**การชำระเงิน**
1. สแกนสินค้าทุกชิ้น **ห้ามคีย์ราคาด้วยมือ** ยกเว้นบาร์โค้ดเสีย และต้องให้หัวหน้ากะรับทราบ
2. ทวนยอดรวมให้ลูกค้าฟังก่อนรับเงิน
3. รับเงินสด → นับต่อหน้าลูกค้า → วางบนลิ้นชัก (ไม่หย่อนลงทันที) → ทอนเงินและนับให้ลูกค้าฟัง → จึงเก็บเงินเข้าลิ้นชัก
4. ส่งใบเสร็จทุกครั้ง พร้อมกล่าวขอบคุณ
5. ยกเลิกรายการ (Void) / คืนเงิน ต้องใช้รหัสหัวหน้ากะเท่านั้น และบันทึกเหตุผลในสมุดควบคุม

---

## FS-03 การควบคุมเงินสดและการส่งกะ

1. ห้ามพนักงานเก็บเงินส่วนตัวไว้ในลิ้นชัก และห้ามยืมเงินจากลิ้นชักทุกกรณี
2. เมื่อเงินสดในลิ้นชักเกิน [10,000] บาท ให้หัวหน้ากะถอนส่วนเกินเข้าตู้นิรภัย พร้อมบันทึกใบถอน
3. ตอนส่งกะ:
   - นับเงินร่วมกัน 2 คน (คนส่ง + หัวหน้ากะ)
   - เทียบกับรายงานยอดขายจาก POS
   - ผลต่างเกิน ± [50] บาท ต้องระบุสาเหตุ และแจ้งผู้จัดการร้าน
   - ผลต่างขาดเกิน [500] บาท หรือขาดซ้ำ [2] ครั้งใน 1 เดือน → ตรวจสอบกล้องวงจรปิดย้อนหลัง
4. บันทึกในใบส่งกะทุกครั้ง: ยอดขาย จำนวนบิล เงินสด บัตร/QR ผลต่าง งานค้างส่งกะถัดไป
5. เงินสดทั้งหมดนำฝากธนาคารทุกวัน [หรือ ทุก __ วัน] โดยมีคนไปด้วยอย่างน้อย 2 คน

## FS-04 การเติมสินค้าและจัดเรียงชั้นวาง

1. เติมสินค้าในช่วงที่ลูกค้าน้อย: [__:__ – __:__] และก่อนปิดร้าน
2. ยึดหลัก **FEFO** — หมดอายุก่อนวางหน้า ของใหม่ไว้ด้านหลังเสมอ
3. จัดหน้าสินค้าให้ตรง (facing) ดันสินค้ามาชิดขอบชั้น ไม่ปล่อยชั้นโหว่
4. ป้ายราคาต้องมีทุกช่อง ตรงกับตำแหน่งสินค้าจริง และตรงกับราคาในระบบ
5. จัดวางตามผังชั้นวาง (planogram) ที่กำหนด **ห้ามย้ายตำแหน่งเองโดยไม่แจ้งผู้จัดการ**
6. ตรวจวันหมดอายุทุกวัน สำหรับสินค้าสด/นม/เบเกอรี่ และทุกสัปดาห์สำหรับสินค้าแห้ง
   - เหลือ [7] วัน → ย้ายไปโซนลดราคา ติดสติกเกอร์ส่วนลดที่อนุมัติแล้ว
   - หมดอายุ → เก็บออกทันที บันทึกเป็นของเสีย (waste) ห้ามนำกลับขึ้นชั้นทุกกรณี
7. บันทึกของเสีย/ของแตกทุกชิ้นในแบบฟอร์ม พร้อมลายเซ็นหัวหน้ากะ

## FS-05 การคืนสินค้า เปลี่ยนสินค้า และข้อร้องเรียน

**เงื่อนไขการรับคืน/เปลี่ยน (ปรับตามนโยบายร้าน)**
- มีใบเสร็จ และภายใน [7] วัน
- สินค้าอยู่ในสภาพเดิม บรรจุภัณฑ์ครบ
- ไม่รับคืน: สินค้าสด อาหารแช่เย็น สินค้าลดราคาล้างสต็อก สินค้าส่วนบุคคล

**ขั้นตอนจัดการข้อร้องเรียน**
1. รับฟังจนจบ ไม่ขัด ไม่โต้เถียง และไม่โทษลูกค้า
2. กล่าวขอโทษต่อความไม่สะดวก และทวนปัญหาเพื่อยืนยันความเข้าใจ
3. แก้ไขตามอำนาจที่มี:

| ระดับปัญหา | ผู้มีอำนาจตัดสิน |
|---|---|
| เปลี่ยนสินค้าชิ้นต่อชิ้น มูลค่าไม่เกิน [500] บาท | พนักงานขาย |
| คืนเงิน / ส่วนลดชดเชยไม่เกิน [2,000] บาท | หัวหน้ากะ |
| เกินกว่านั้น หรือกรณีอาหารเป็นพิษ อุบัติเหตุในร้าน สื่อ/โซเชียล | ผู้จัดการร้าน หรือเจ้าของร้าน เท่านั้น |

4. บันทึกทุกเคสลงสมุดข้อร้องเรียน: วันที่ ลูกค้า ปัญหา สิ่งที่ทำไป ผลลัพธ์
5. ทบทวนข้อร้องเรียนย้อนหลังในที่ประชุมประจำเดือน เพื่อหาสาเหตุที่เกิดซ้ำ

## FS-06 การปิดร้าน

1. ประกาศแจ้งลูกค้าก่อนปิด [15] นาที **ห้ามไล่ลูกค้าหรือปิดไฟก่อนเวลา**
2. ปิดระบบ POS ออกรายงานสรุปยอดขายประจำวัน (Z-report)
3. นับเงินปิดกะตามข้อ FS-03 เก็บเงินเข้าตู้นิรภัย
4. เติมสินค้าให้เต็มชั้น จัดหน้าสินค้า และเก็บของที่ลูกค้าวางผิดที่กลับที่เดิม
5. เก็บสินค้าที่ต้องแช่กลับเข้าตู้ ตรวจอุณหภูมิตู้แช่และบันทึก
6. ทำความสะอาดพื้น เคาน์เตอร์ ห้องน้ำ ทิ้งขยะ
7. ตรวจปิดน้ำ ไฟ แอร์ อุปกรณ์ไฟฟ้าทุกจุด (ยกเว้นตู้แช่และกล้องวงจรปิด)
8. ตรวจว่าไม่มีคนตกค้างในร้าน ล็อกประตูทุกบาน เปิดสัญญาณกันขโมย
9. หัวหน้ากะเซ็นเช็กลิสต์ปิดร้าน และส่งรายงานยอดขายให้ผู้จัดการ

## FS-07 การนับสต็อกและควบคุมของสูญหาย

1. **นับย่อย (Cycle count):** ทุกสัปดาห์ สุ่มนับ [20–30] SKU เน้นสินค้าขายดี ราคาสูง และสินค้าที่หายบ่อย
2. **นับใหญ่ (Full count):** ทุก [3–6] เดือน ทำนอกเวลาขายหรือปิดร้านครึ่งวัน
3. ผู้นับต้องมี 2 คน คนหนึ่งนับ อีกคนบันทึก และห้ามให้ผู้รับผิดชอบสินค้ากลุ่มนั้นนับกลุ่มตัวเองเพียงลำพัง
4. เทียบผลกับระบบ วิเคราะห์ผลต่าง:
   - ผลต่างเกิน [1%] ของมูลค่าสต็อกกลุ่มนั้น → ตรวจสอบสาเหตุก่อนปรับยอด
   - สาเหตุที่ต้องตรวจก่อนเสมอ: รับของไม่ลงระบบ / ขายไม่สแกน / บันทึกของเสียไม่ครบ / การลักทรัพย์
5. การปรับยอดสต็อก (Stock adjustment) ต้องได้รับอนุมัติจากผู้จัดการร้านเท่านั้น
6. ทบทวนอัตราของสูญหาย (shrinkage) รายเดือน เป้าหมายไม่เกิน [1–2]% ของยอดขาย

## FS-08 ความปลอดภัยและเหตุฉุกเฉิน

1. กล้องวงจรปิดต้องบันทึกตลอดเวลา และเก็บข้อมูลย้อนหลังอย่างน้อย [30] วัน
2. ห้ามพนักงานอยู่คนเดียวในร้านช่วงกลางคืน หากเลี่ยงไม่ได้ ต้องมีปุ่มฉุกเฉินและระบบติดต่อ
3. กรณีถูกปล้น/ชิงทรัพย์: **ความปลอดภัยของคนสำคัญกว่าเงิน** ให้ปฏิบัติตามที่คนร้ายบอก ไม่ต่อสู้ จดจำรูปพรรณ แล้วโทร 191 ทันทีเมื่อปลอดภัย
4. กรณีจับสงสัยการลักขโมย: ห้ามพนักงานควบคุมตัวหรือค้นตัวลูกค้าเอง ให้แจ้งหัวหน้ากะและเจ้าหน้าที่
5. ตรวจถังดับเพลิงทุก [6] เดือน ซ้อมอพยพปีละ [1] ครั้ง และติดผังทางหนีไฟให้เห็นชัด
6. กรณีเกิดอุบัติเหตุกับลูกค้าในร้าน: ปฐมพยาบาล → บันทึกเหตุการณ์ + ถ่ายภาพจุดเกิดเหตุ → แจ้งผู้จัดการร้านทันที **ห้ามรับผิดหรือรับปากชดเชยเอง**

# ส่วนที่ 6 — การบังคับใช้

1. พนักงานทุกคนต้องอ่านและเซ็นรับทราบ SOP ฉบับนี้ก่อนเริ่มงาน
